# ماسنجر لايت — Masingar Lite 🕌💬

تطبيق **خفيف جداً على طريقة فيسبوك لايت** — لكن ليس للبحث عن أشخاص وليس عالمياً:
دائرة خاصة صغيرة (**٥ أعضاء كحد أقصى**) تتواصل فيما بينها فقط.

- 📱 **التسجيل برقم الهاتف** (كود تحقق يظهر داخل التطبيق — بدون SMS وتكاليفه)
- 👥 **من سجّل يظهر للجميع**: قائمة الأعضاء تعرض الاسم + رقم الهاتف + الحالة (متصل/آخر ظهور)
- 🏠 **منشورات** بنمط فيسبوك: نص + صورة + إعجابات ❤️ + تعليقات 💬
- 💬 **دردشة جماعية** للدائرة كلها مع مؤشر «يكتب الآن…»
- 🚫 **لا بحث عن أشخاص ولا غرباء**: الدائرة مكتملة = التسجيل مغلق تلقائياً
- 🪶 **حجم ومساحة صغيران**: بلا قاعدة بيانات، بلا مكتبات ثقيلة، والصور تُضغط في الجوال قبل الإرسال، والأرشيف يُقلَّم تلقائياً

| الجزء | الوصف |
|---|---|
| `server/` | سيرفر Node.js صغير (Express + ws فقط): دخول بالهاتف، منشورات، دردشة، حضور لحظي |
| `web/` | تطبيق الويب (PWA عربي RTL) — يُثبَّت على الجوال بضغطة واحدة |
| `android/` | غلاف WebView مصغّر — APK بضع مئات الكيلوبايت |

---

## 1) تجربة سريعة (الآن)

```bash
npm install
npm start          # السيرفر على المنفذ 3000
```

افتح `http://localhost:3000` ثم:

1. اختر رمز الدولة واكتب رقم هاتفك (مثلاً `771234567` مع `+967`).
2. اضغط **إرسال كود التحقق** — الكود يظهر داخل التطبيق مباشرة (وضع الدائرة الخاصة).
3. اكتب اسمك ودخول — ستظهر في قائمة الأعضاء مع رقمك أمام الجميع.

> للتجربة بين أكثر من عضو: افتح التطبيق في أكثر من نافذة/جوال وسجّل أرقاماً مختلفة.
> عند اكتمال ٥ أعضاء يُغلق التسجيل تلقائياً ويظهر «الدائرة مكتملة».

## 2) تثبيته كتطبيق على الجوال (بدون أي بناء)

افتح الرابط من متصفح Chrome على الجوال ثم **⋮ ← إضافة إلى الشاشة الرئيسية** —
يعمل كتطبيق مثبّت (PWA) بواجهة كاملة ويعمل دون شبكة لآخر ما تم تحميله.

## 3) بناء APK أندرويد (خفيف جداً)

```bash
cd android
# اضبط عنوان سيرفرك في local.properties (انظر local.properties.example)
echo "SERVER_URL=https://your-server.com" > local.properties
gradle :app:assembleRelease
```

الـ APK الناتج في `android/app/build/outputs/apk/release/` —
غلاف WebView واحد بدون أي مكتبات خارجية، لذلك حجمه **بضع مئات الكيلوبايت فقط**
مقابل عشرات الميجابايت للتطبيقات الكاملة.

> أو اترك GitHub Actions يبنيه لك تلقائياً عند كل دفع (`.github/workflows/main.yml`).

## 4) النشر على سيرفر

الأسهل — Docker:

```bash
cd deploy && docker compose up -d --build
```

أو مباشرة بـ Node 18+:

```bash
SERVER_URL ليس مطلوباً — فقط: PORT=3000 node server/src/index.js
```

كل البيانات (ملف JSON واحد + الصور) في مجلد `server/data/` —
انسخه احتياطياً بين الحين والآخر وهذا كل شيء.

### متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ السيرفر |
| `APP_NAME` | `ماسنجر لايت` | اسم الدائرة (يظهر في الدخول والواجهة) |
| `MAX_MEMBERS` | `5` | حد الأعضاء الأقصى |
| `JOIN_CODE` | فارغ | رمز انضمام: إذا ضُبط لن يستطيع أحد التسجيل إلا من يعرفه (**موصى به عند النشر على الإنترنت**) |
| `MAX_MESSAGES` | `1000` | أرشيف الرسائل المحفوظ (يُقلَّم تلقائياً) |
| `MAX_POSTS` | `200` | أرشيف المنشورات المحفوظ |
| `DATA_DIR` | `server/data` | مجلد البيانات |

## 5) الاختبارات

```bash
npm test    # يفحص الدخول، حد الأعضاء، المنشورات، الإعجابات، التعليقات، الدردشة
```

## 6) لماذا «لايت» فعلاً؟

- **بلا قاعدة بيانات**: ملف JSON واحد + مجلد صور — لا SQLite ولا Redis ولا شيء يُجمَّع.
- **بلا مكتبات ثقيلة**: السيرفر يعتمد على `express` و`ws` فقط، والتطبيق كود أصلي واحد بدون أي framework.
- **بلا WebRTC/Firebase/مزامنة جهات اتصال**: لا مكالمات ولا إشعارات FCM — أُزيلت كلها لصالح الحجم الصغير.
- **الصور تُضغط في الجوال** (≤ 280KB و1280px) قبل إرسالها، والأرشيف يُقلَّم باستمرار — مساحة السيرفر تبقى بضع ميجابايت.
