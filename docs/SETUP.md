# دليل التشغيل — ماسنجر لايت

كل ما تحتاجه لتشغيل ونشر تطبيق الدائرة الصغيرة.

## المتطلبات

- Node.js 18 أو أحدث (للسيرفر)
- متصفح حديث على الجوال أو الحاسوب (للتطبيق)
- (اختياري) Docker، وJDK 17 + Gradle 8.9 لبناء APK أندرويد

## 1) تشغيل السيرفر محلياً

```bash
npm install
npm start
# أو للتطوير مع إعادة تشغيل تلقائية:
npm run dev
```

افتح `http://localhost:3000`.

## 2) كيف يعمل الدخول؟

1. المستخدم يكتب رقم هاتفه مع رمز الدولة.
2. السيرفر يولّد كوداً من ٦ أرقام صالحاً ١٠ دقائق.
3. **وضع الدائرة الخاصة**: بما أن التطبيق لدائرة عائلية/أصدقاء صغيرة ولا يوجد مزوّد SMS،
   يظهر الكود مباشرة داخل التطبيق.
4. العضو الجديد يكتب اسمه، ويظهر فوراً في قائمة الأعضاء (الاسم + الرقم) أمام الجميع.
5. العضو الحالي يدخل بنفس الطريقة في أي وقت.

> عند اكتمال الدائرة (٥ أعضاء) يرفض السيرفر أي رقم جديد برسالة «الدائرة مكتملة»،
> ويستمر الأعضاء الحاليون في الدخول دائماً.

## 3) حماية التسجيل (مهم عند النشر على الإنترنت)

بما أن كود التحقق يظهر داخل التطبيق، أي شخص يعرف الرابط قد يحاول التسجيل.
لمنع الغرباء عن الدائرة اضبط **رمز انضمام**:

```bash
JOIN_CODE=4521 node server/src/index.js
```

الآن لا يستطيع أحد التسجيل إلا من يعرف الرمز (وزّعه على أفراد دائرتك فقط).
الأعضاء الحاليين لا يُطلب منهم الرمز عند الدخول مجدداً.

## 4) النشر

### Docker (الأسهل)

```bash
cd deploy
docker compose up -d --build
```

البيانات تُحفظ في وحدة تخزين `masingar-data` (ملف JSON + الصور).

### Node مباشرة (systemd أو pm2 أو screen)

```bash
PORT=3000 JOIN_CODE=4521 APP_NAME="دائرة العائلة" node server/src/index.js
```

### بعد النشر

- استخدم HTTPS (بروكسي مثل Caddy أو nginx) لتعمل ميزة «تثبيت التطبيق» PWA وWebSocket بأمان.
- حدّث `SERVER_URL` في `android/local.properties` ثم ابنِ الـ APK ليشير إلى سيرفرك.

## 5) بناء APK أندرويد

```bash
cd android
echo "SERVER_URL=https://your-server.com" > local.properties
gradle :app:assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

- التطبيق مجرد WebView يفتح سيرفرك — الحجم بضع مئات الكيلوبايت.
- بدون مفتاح توقيع خاص يُوقَّع بمفتاح التصحيح ويكفي للتثبيت الشخصي.
  لتوقيع حقيقي املأ `KEYSTORE_FILE` وما يليه في `local.properties`.

### تغيير عنوان السيرفر من داخل الجهاز (بدون إعادة بناء)

ملف الـ APK واحد يصلح لأي سيرفر:

- **عند أول تشغيل**: إذا كان العنوان المدمج خاصاً بالمحاكي (`10.0.2.2`) تظهر
  نافذة تلقائياً تكتب فيها عنوان سيرفرك ويُحفظ في الجهاز.
- **عند فشل الاتصال**: تظهر شاشة عربية فيها «إعادة المحاولة» و
  «تغيير عنوان السيرفر».
- العنوان المحفوظ يبقى في الجهاز حتى لو أعدت تثبيت التطبيق فوق نفسه.

## 6) النسخ الاحتياطي والاستعادة

كل شيء داخل مجلد البيانات (`server/data/` افتراضياً أو `/data` في Docker):

```
data/
├── app.json     ← الأعضاء والمنشورات والرسائل (ملف واحد صغير)
└── media/       ← الصور المضغوطة
```

انسخ المجلد = نسخة احتياطية كاملة. الاستعادة = ضعه مكانه وشغّل السيرفر.

## 7) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لا يوجد اتصال بالخادم» | تأكد أن السيرفر يعمل وأن `SERVER_URL` في الـ APK صحيح |
| التطبيق لا يفتح صورة الاختيار في أندرويد | الميزة مدعومة في غلاف WebView عبر منتقي الملفات |
| الدائرة مكتملة بالخطأ | اضبط `MAX_MEMBERS` أو احذف `data/app.json` للبدء من جديد |
| نسيت رمز الانضمام | هو متغير البيئة `JOIN_CODE` — غيّره وأعد التشغيل |
