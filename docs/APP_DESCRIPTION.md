# ماسنجر (Masingar) — وصف كامل للتطبيق

> تطبيق دردشة ومكالمات (صوت + صورة) مفتوح المصدر، عربي أولاً، مشفّر من طرف إلى طرف،
> وتشغّله أنت على سيرفرك الخاص. يتكوّن من ثلاثة أجزاء تعمل معاً:
> **سيرفر Node.js** + **عميل ويب (PWA)** + **تطبيق أندرويد**.

---

## 1) الفكرة في سطرين

«واتساب خاص بك»: نفس الفكرة (دردشة + مكالمات + مجموعات عبر رقم الهاتف)، لكن **البيانات عندك لا عند شركة**،
والتشفير يعمل افتراضياً على كل رسالة وكل ملف، وواجهته عربية بالكامل ويعمل على الشبكات الضعيفة.

---

## 2) لمن يُناسب؟

| الحالة | مناسب؟ | لماذا |
|---|---|---|
| عائلة / فريق / مجموعة تريد محادثات خاصة بعيداً عن الشركات | ✅ ممتاز | سيرفرك أنت، ولا أحد يقرأ الرسائل |
| شركة تريد محادثات داخلية مشفّرة | ✅ ممتاز | يُنصب داخل الشركة أو على سيرفرها |
| دولة أو منطقة تريد تطبيقاً محلياً برمز دولتها | ✅ ممتاز | رمز الدولة الافتراضي قابل للضبط (اليمن `967` افتراضياً) |
| شخص يريد بديلاً لواتساب يفتحه **كل** معارفه | ❌ لا | التطبيق يحتاج أن يثبّت الطرف الآخر النسخة نفسها ويشترك معك في السيرفر |

## 3) المزايا بالتفصيل

### أ) الحساب وجهات الاتصال
- تسجيل الدخول **برقم الهاتف + كود تحقق (OTP)** — لا بريد ولا كلمة مرور.
- **رمز دولة افتراضي قابل للضبط** (`DEFAULT_COUNTRY_CODE`، الافتراضي `967`) + قائمة دول كاملة.
- **مزامنة جهات الاتصال**: يطابق أرقام هاتفك مع المسجّلين فيظهرون تباعاً في تبويب «جهات الاتصال».
- الملف الشخصي: الاسم، النبذة، الصورة، حالة الاتصال وآخر ظهور.

### ب) المحادثات
- محادثات **فردية ومجموعات** (إنشاء مجموعة، أعضاء، عنوان، صورة).
- أنواع الرسائل: **نص، صورة، فيديو، تسجيل صوتي، ملف** (حتى 32 ميغابايت قابل للزيادة).
- **الرد على رسالة معيّنة** (اقتباس)، نسخ، حذف.
- **حالات الإرسال**: `جارٍ الإرسال ✓` → `وصلت ✓✓` → `قُرئت ✓✓` (جدول استلام منفصل لكل عضو).
- **مؤشر الكتابة** «يكتب الآن…»، والاتصال/آخر ظهور.
- **بحث** بالاسم أو الرقم، كتم المحادثة، عدّاد الرسائل غير المقروءة.
- **يعمل بدون إنترنت**: الرسالة تُحفظ في طابور وتُرسل تلقائياً عند عودة الاتصال.

### ج) المكالمات (صوت وفيديو)
- مكالمات **صوتية ومرئية** عبر WebRTC، مع شاشة اتصال كاملة (كتم، مكبر صوت، تبديل الكاميرا، إيقاف الفيديو).
- **تكيّف تلقائي مع الشبكة**: يقيس الجودة باستمرار ويقلّل الدقة ومعدل الإطارات عند الضعف.
- **رجوع للصوت فقط**: عند تدهور الشبكة يوقف الفيديو تلقائياً ويُبقي الصوت، ثم يُرجع الفيديو عند التحسّن.
- ثلاثة أوضاع جودة: توفير بيانات / تلقائي / عالية الدقة 720p.
- **إحصائيات مباشرة** أثناء المكالمة (السرعة، الفقد، زمن التأخير، الترميز).
- سجل مكالمات كامل (صادرة/واردة/فائتة) + إشعار بالمكالمة الفائتة.
- **TURN/STUN** للعمل خلف شبكات الجوال و NAT: السيرفر يولّد بيانات دخول مؤقتة (HMAC) فلا تُكشف الأسرار.

### د) الخصوصية (أهم ما يميّزه)
| الميزة | الشرح |
|---|---|
| **تشفير طرف-ل-طرف (E2EE)** | X25519 لتبادل المفاتيح + HKDF-SHA-256 + AES-256-GCM. السيرفر يحفظ **نصاً مشفّراً فقط** — الرسائل والملفات ومفاتيح المجموعات. |
| **الملفات مشفّرة قبل الرفع** | الملف يُشفَّر على الجهاز قبل إرساله، ولا يُفتح إلا عند أعضاء المحادثة. |
| **خلفية محادثة مشتركة** | من يغيّر خلفية المحادثة تظهر للطرف الآخر **في نفس اللحظة** (6 خلفيات جاهزة + إلغاء). |
| **تنبيه لقطة الشاشة وتسجيل الشاشة** | إذا التقط أحد الطرفين صورة للشاشة (أو سجّلها) يصل الطرف الآخر إشعار ويبقى كرسالة نظام في المحادثة. |
| **بلا إعلانات ولا تتبّع** | لا يحوي أي SDK تحليلي أو إعلاني. |

### هـ) التجربة والتشغيل
- **واجهة عربية أولاً** مع اتجاه RTL، وملف ترجمة جاهز (عربي/إنجليزي) + اختيار اللغة والمظهر (فاتح/داكن/حسب النظام).
- **يعمل على الويب والتلفون**: عميل ويب (PWA) قابل للتثبيت على الهاتف وسطح المكتب + تطبيق أندرويد أصلي (Compose/Kotlin).
- **إشعارات**: داخل التطبيق عبر WebSocket دائماً، و**FCM** اختيارياً عند إغلاقه.
- **خفيف على الشبكة**: ضغط الوسائط و«توفير البيانات» لشبكات 2G/3G.

## 4) المعمارية التقنية

```
┌───────────────┐   HTTPS + WSS   ┌────────────────────────┐
│ أندرويد       │◄───────────────►│                        │
│ (Kotlin/      │                 │  سيرفر Node.js (≥20)   │
│  Compose)     │                 │  • REST  (Express)     │
├───────────────┤                 │  • WebSocket (ws)      │
│ ويب (PWA)     │◄───────────────►│  • SQLite (ملف واحد)   │
│ vanilla JS    │                 │  • تخزين مرفقات مشفّرة │
└───────────────┘                 └────────────────────────┘
                                             │
                                    coturn (TURN) + nginx
```

| الجزء | التقنية | الحالة |
|---|---|---|
| السيرفر | Node.js + Express + ws + SQLite | ✅ مُختبر (43/43 + 12/12) |
| عميل الويب | JavaScript نقية (لا إطارات) + Service Worker | ✅ مُختبر (45 اختباراً في DOM حقيقي) |
| أندرويد | Kotlin + Jetpack Compose + WebRTC | ⏳ كود كامل، بانتظار أول بناء حقيقي |
| المكالمات | WebRTC + TURN | كود كامل، يحتاج TURN للعمل عبر الإنترنت |
| CI/CD | GitHub Actions (بناء APK تلقائياً) | جاهز في `docs/github-actions-ci.yml` |

### أين هو **أقل** منهم (بصراحة)
| البند | الحقيقة |
|---|---|
| **قاعدة المستخدمين** | واتساب فيه ملياران. ماسنجر يبدأ من صفر: **لن تجد أحداً عليه إلا إذا ثبّته من تريد محادثته**. هذه أكبر عقبة، وهي عقبة اجتماعية لا برمجية. |
| **الأجهزة المتعددة** | حالياً **هوية تشفير واحدة لكل حساب**: فتح الحساب على جهاز ثانٍ يستبدل مفتاحه، فيفقد الجهاز الأول القدرة على فكّ رسائله الجديدة. (واتساب يحلّها بنظام أجهزة مرتبطة.) |
| **النسخ الاحتياطي السحابي** | غير موجود بعد: فقدان الهاتف = فقدان السجل المحلي. |
| **مزايا اجتماعية** | لا ستوريز/حالات، لا قنوات، لا مجتمعات، لا منشورات عامة، لا دفع مالي. هو تطبيق **مراسلة** لا شبكة اجتماعية. |
| **النطاق والعتاد** | واتساب يعمل على آلاف الخوادم. سيرفرك (512MB/1vCPU) يكفي لمئات المستخدمين، لا لملايين. |
| **النضج التشغيلي** | لا يوجد ضغط وسائط متقدّم، ولا اعتدال آلي على المحتوى، ولا أنظمة مكافحة البريد المزعج، ولا دعم عملاء. |
| **المنصات** | أندرويد + ويب فقط. لا iOS بعد. |

### أين هو **أفضل** منهم
| البند | الشرح |
|---|---|
| **تملك بياناتك** | السيرفر عندك: لا تُباع بياناتك ولا تُحلَّل، ولا تُغلق حسابك شركة. |
| **تشفير كل شيء** | الرسائل، والملفات، ومفاتيح المجموعات — السيرفر لا يرى غير نص مشفّر (مُختبر). |
| **خلفية مشتركة** | ميزة اجتماعية لطيفة غير موجودة في واتساب. |
| **تنبيه لقطات الشاشة** | يخبرك إذا صوّر الطرف الآخر المحادثة — أقوى من واتساب في الخصوصية. |
| **عربي أولاً** | واجهة RTL ونصوص عربية الأصل، لا ترجمة لاحقة. |
| **قابل للتعديل** | الكود مفتوح (MIT): عدّل الواجهة، أضف مزايا، غيّر الهوية. |

## 7) الإجابة المباشرة: هل يعمل مثل واتساب وفيسبوك؟

**وظيفياً: نعم في نطاقه.** من يثبّت التطبيق على سيرفرك سيجد تجربة قريبة من واتساب:
محادثات، مجموعات، مكالمات صوت وفيديو، وسائط، إشعارات، وتشفير كامل.

**لكنه ليس بديلاً لواتساب ولا شبكة تواصل اجتماعية:**
- واتساب/فيسبوك قيمتهما الأساسية في **عدد الناس الموجودين فيهما** — وهذه ميزة لا تُبرمج، تُكتسب بالوقت.
- لا توجد فيه مزايا «الشبكة الاجتماعية» (منشورات، ستوريز، قنوات، صفحات).
- يحتاج منك تشغيل سيرفر وصيانته (أو من يستضيفه لك)، وضبط TURN لنجاح المكالمات.

**الخلاصة:** هو «واتساب لجماعتك» — ممتاز لعائلة أو فريق أو شركة أو مجتمع يريد محادثات خاصة بعيداً عن الشركات،
وليس منافساً لواتساب في السوق العام.

## 8) ما يحتاجه ليعمل فعلياً عندك

1. **سيرفر** (أي VPS صغير أو جهاز داخلي): `Node ≥ 20` + ملف SQLite. لا قاعدة بيانات خارجية.
2. **نطاق + HTTPS** (إلزامي للكاميرا والميكروفون وتثبيت PWA).
3. **coturn (TURN)** لنجاح المكالمات عبر شبكات الجوال.
4. **مزوّد SMS** لإرسال كود التحقق (Twilio أو ويب‌هوك) — أو `SMS_PROVIDER=none` للتجربة.
5. **FCM** (اختياري) لإشعارات المكالمات والتطبيق مغلق.

- مفاتيح مجموعات دوّارة عند تغيّر الأعضاء، وصلاحيات وروابط دعوة.
